B - Unit and Lesson Planning

Conceptual map

A conceptual map of the Form 4 Spreadsheet unit.

Text version of the conceptual map

Form 4 Spreadsheet Unit Plan: building skills from fundamentals to real-world application.

  • Lesson 1, Excel functions (1/5): purpose and uses of functions; function classification (ABS, AVERAGE, MAX, MIN, COUNT); logical and lookup functions (IF, VLOOKUP); financial and date functions (PMT, DATE); grouping functions by task type.
  • Lesson 2, Data formatting, sorting and filtering (2/5): numeric formatting (data types); sorting data (primary and secondary fields); filtering criteria (single, multiple, complex); data integrity (accuracy and integrity); data operations (insert, delete, modify).
  • Lesson 3, Chart operations (3/5): chart types (column, bar, line, pie); chart selection (appropriate chart for trends); chart labelling (axes labels, data labels, graph titles).
  • Lesson 4, Chart preparation (4/5): creating and evaluating visual data representations; chart formatting (appearance and style); editing and refining charts to communicate clearly.
  • Lesson 5, Practical application and project (5/5): apply skills to real-world scenarios; create complete spreadsheets with data, formulas, charts and reports; evaluate and present visual representations.
  • Final outcome: create, analyse and present data effectively using spreadsheet software.

How the lessons connect, as labelled on the map: builds formula skills; uses data organized from Lesson 2; organised data is prepared for visualisation; visual data supports analysis and reporting; visual reports are used to make informed decisions; integrates all skills for real-world use.
